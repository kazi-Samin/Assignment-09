# 🏥 MediCare – Doctor Appointment Platform

MediCare is a modern full-stack doctor appointment booking platform where users can explore doctors, book appointments, manage bookings, and maintain their healthcare profile easily.

The platform provides a smooth and responsive user experience with secure authentication and a clean dashboard system.

---

# ✨ Features

- User Authentication System
- Google Sign In
- Doctor Listing
- Appointment Booking
- Dashboard Management
- User Profile System
- Responsive Mobile-Friendly Design
- Secure Backend API
- Real-Time Booking Management
